# Manglam Clinic — Pathya Apathya Print App
## Complete Build Prompt for Replit

---

## PROJECT OVERVIEW

Build a **web app** for **Manglam Skin Care Clinic** (Dr. Vijay Girgalani, Rajkot) that generates **printable Pathya-Apathya patient handout sheets** for Ayurvedic diseases. The doctor selects a disease + patient name + language, previews the sheet, and prints it to hand to the patient.

---

## TECH STACK

- **Frontend only** — plain HTML + CSS + Vanilla JS (no frameworks needed)
- Single `index.html` file
- No backend required
- Print-optimized CSS (`@media print`)
- Google Fonts: `Noto Sans Gujarati`, `Noto Sans Devanagari`, `Poppins`

---

## APP STRUCTURE

### Two panels side by side (on desktop):

**LEFT PANEL — Control Panel (no-print)**
- Clinic branding at top
- Patient name input (text field, auto-suggest from recent names stored in localStorage)
- Disease selector (dropdown)
- Language toggle: Gujarati | Hindi | English
- Big "Print Sheet" button
- List of all available diseases (clickable)

**RIGHT PANEL — Live Print Preview**
- Shows the formatted sheet in real time as selections change
- This is exactly what gets printed

## LANGUAGE TOGGLE BEHAVIOR

Three language modes. When toggled, ALL text in the sheet changes:

| Element | Gujarati | Hindi | English |
|---|---|---|---|
| Disease name | અમ્લપિત્ત | अम्लपित्त | Amlapitta |
| Section label | અનાજ | अनाज | Grains |
| Item text | જૂનો ચોખો | पुराना चावल | Old rice |
| Sub-text | always show English translation small below |

In Gujarati and Hindi modes: primary text in that script, small English below each item.
In English mode: English only, no secondary text needed.

## PATIENT NAME FEATURE

- Text input in control panel labeled "Patient Name"
- As user types, auto-suggest from names saved in `localStorage` key `"mgc_patients"`
- On print/select: save that name to localStorage (keep last 50 names, no duplicates)
- The name appears on the printed sheet in the patient name bar
- Add a small "Clear" button to remove name from field

## IMPORTANT NOTES

1. The app should work **offline** after first load (Google Fonts will cache)
2. Print should produce a **clean A4 sheet** — no browser chrome, no control panel
3. Patient name stored in localStorage should **persist across sessions**
4. The hexagon background pattern should be an **inline SVG data URI** (no external images)
5. All Gujarati text must use **Noto Sans Gujarati** font
6. All Hindi text must use **Noto Sans Devanagari** font
7. Default language on load: **Gujarati**
8. Default disease on load: **Amlapitta**
